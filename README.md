# Automotive Sales Analysis
Automotive Sales Analysis and Interactive Power BI Dashboard using SQL, Python, Excel, and Data Analytics techniques.

## 📊 Project Overview

This project was developed as part of the Data Analyst Bootcamp organized by KarirNex by PT Ebiz Karisma Internasional.

The project focuses on analyzing automotive sales data from multiple branches and transforming raw transactional data into an interactive Power BI dashboard.

The dashboard provides insights into sales performance, transaction activity, product performance, payment methods, transaction status, monthly sales trends, and branch performance.

## 🎯 Business Objectives

The main objectives of this project are to:

- Analyze overall sales performance
- Identify the highest-performing product categories
- Identify the highest-performing branches
- Analyze the top 5 products by sales
- Understand monthly sales trends
- Analyze payment method distribution
- Monitor Completed, Cancelled, and Refund transactions
- Compare SUV and MPV performance
- Analyze branch-level KPIs
- Provide actionable insights for management

## 📈 Dashboard Features

The dashboard includes:

- Total Sales
- Total Transactions
- Total Quantity
- Completion Rate
- Top 5 Products by Sales
- Sales by Branch
- Sales by Category
- Monthly Sales Trend
- Payment Type Distribution
- Transaction Status Composition
- SUV vs MPV Comparison
- Branch KPI Analysis

## 🔍 Key Insights

### 1. Payment Method

Kredit was the most frequently used payment method, accounting for 4,253 transactions or 42.53% of total transactions.

### 2. Sales Category

SUV generated the highest sales among the available vehicle categories.

### 3. Branch Performance

Malang recorded the highest total sales among the analyzed branches.
